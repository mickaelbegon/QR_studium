# QR_studium

Application destinée aux professeurs pour **lire, corriger et créer** des questions
StudiUM (Moodle), parcourir rapidement une banque de questions, assembler des examens
et faire évoluer questions et réponses dans le temps.

- Entrée / sortie : format **Moodle XML** (import/export de la banque de questions StudiUM).
- Les banques de questions réelles vont dans `data_prive/` (ignoré par git, jamais publié).
